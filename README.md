# Matera del Sur — Tienda online (HTML + CSS)

Proyecto para **Desarrollo de Software III**. Sitio de una tienda ficticia de productos materos,
hecho solo con **HTML y CSS** (sin JavaScript) y publicado con **GitHub Pages**.

## Páginas
| Archivo | Contenido | Temas aplicados |
|---|---|---|
| `index.html` | Portada, beneficios, destacados, categorías, nosotros | Estructura, control de texto, enlaces |
| `productos.html` | Catálogo por categorías | Anclas internas, atributo `download`, grilla |
| `envios.html` | Costos de envío, medios de pago, preguntas frecuentes | Tablas (`caption`, `thead`, `tfoot`, `rowspan`, `colspan`, `scope`) |
| `contacto.html` | Formulario de consulta y mapa | Formularios con validación nativa, `iframe` |

## Estructura
```
index.html  productos.html  envios.html  contacto.html
css/estilos.css      -> estilos, animaciones y diseño responsivo
docs/                -> catálogo en PDF descargable
```
